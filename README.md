## My process

### Built with

- Semantic HTML5 markup
- Tailwind CSS
- CSS Grid
- Mobile-first workflow

### What I learned

This was my first time using Tailwind CSS for a Frontend Mentor challenge. Before starting, I redesigned some of my previous challenges that I had originally built with pure CSS and then tried to achieve the same results using Tailwind.

This approach was highly effective, as it allowed me to compare the two approaches directly and become more confident with Tailwind's utility-first workflow.

I also explored Tailwind's documentation, especially topics such as grid-cols, col-span, responsive variants, media queries, and breakpoints.

### AI Collaboration

I used both ChatGPT and Gemini during this project.

Gemini was mainly involved in the initial workflow and implementation, such as extracting design tokens from the original design and helping with the initial HTML structure and Tailwind setup.

This was a different experience for me because it was one of the first times I allowed AI to participate directly in the implementation process. However, I reviewed each step after it was completed rather than blindly accepting the generated code.

In fact, reviewing the AI output was necessary because it occasionally introduced unnecessary default values, invented problems that did not actually exist, or suggested solutions to problems that were not relevant to the implementation.

Overall, AI was useful for handling some of the more routine parts of the implementation and providing an initial structure. However, I still handled the parts that required design and layout decisions myself, such as defining the responsive breakpoints and planning the grid layout.

The workflow was essentially: AI handled some of the repetitive implementation work, while I focused on the actual layout decisions, reviewed the generated code, and corrected or refined it where necessary.

Finally, I used ChatGPT as a final code-review step before publishing the project, mainly to review the implementation from a best-practices perspective and catch any remaining issues.
